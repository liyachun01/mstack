# runtime/ — this installation's records

Everything here is about **this machine's** mstack installation, not mstack itself:
- receipts of installs, removals, recoveries and qualifications;
- dated notes and decisions;
- proposals, handovers and status pages.

It never ships and product code never reads it. See [docs/design/012-PRODUCT-VS-RUNTIME.md](../docs/design/012-PRODUCT-VS-RUNTIME.md).

New records go here from 2026-10-29: `journal/` (dated notes), `receipts/` (machine-readable records),
`docs/` (proposals and reports). Older records are still under `infra/maintenance/`, `infra/*/qualification.json`
and `docs/` until MST-22 moves them.
